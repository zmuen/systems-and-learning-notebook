# Types of ML Models

| Type | Best For | Examples |
| -------- | -------- |
| Linear Models | Simple, interpretable tasks | Linear/Logistic Regression |
| Tree-based Models | Tabular data, feature importance | Decision Trees, Random Forests, XGBoost |
| Support Vector Machines | Classification with clear margins | DSVM, SVR |
| Neural Networks | Complex patterns, large data | MLPs, CNNs, RNNs |
| Transformers | Sequential/language data | BERT, GPT, T5 |
| Ensemble Models | Combining weak learners | Bagging, Boosting, Stacking |
