# Relevant concept from graph theory
## Adjacency matrix
The matrix representation requires a single memory access to check if an edge exists but it requires $n^{2}$ space. The adjacency matrix representation allows us to use tools from linear algebra to study graph properties.
Av=λv
- $\lambda$: eigenvalue
- v: eigenvector
This means that when the matrix A acts on the vector v, the direction of the vector does not change; it is only scaled by a factor of λ.

## Adjacency list
The adjacency list representation requires n+2*m space because every edge is included twice. 


## Walks, paths and cycles
A walk of length $k$ from node $s$ to node $t$ is a sequence

$$
s=v_0,v_1,\dots,v_k=t
$$

such that $(v_{i-1},v_i)\in E$ for every $i=1,\dots,k$.

A path is a walk in which all vertices are distinct.

A cycle is a closed walk with

$$
v_0=v_k
$$

and no repeated vertices other than the first/last one.

The number of walks of length $k$ from node $s$ to node $t$ is given by the $(s,t)$ entry of $A^k$:

$$
(A^k)_{st}=\sum_{v\in V}(A^{k-1})_{sv}A_{vt}
$$

In particular,

$$
(A^1)_{st}=A_{st}, \qquad (A^2)_{st}=\sum_{v\in V}A_{sv}A_{vt}
$$

The length of a shortest path between $s$ and $t$ is

$$
d(s,t)=\min \{k\ge 0:(A^k)_{st}>0\}
$$

A complete graph (or “clique”) is a special case of a regular network in which every vertex is connected to every other vertex (k=n-1).

### Transition matrix
For an undirected graph, let the degree of node $i$ be

$$
k_i=\sum_j A_{ij}
$$

Then the transition matrix for a simple random walk is

$$
P_{ij}=\frac{A_{ij}}{k_i}
$$

or in matrix form

$$
P=D^{-1}A
$$

where $D=\mathrm{diag}(k_1,\dots,k_n)$.

### Random walk

If $p^{(t)}$ is the probability distribution at time $t$, then

$$
p^{(t+1)}=p^{(t)}P
$$

Stationary distribution: describes the probability of staying at the corresponding node after continuous random walks

A stationary distribution $\pi$ satisfies

$$
\pi=\pi P, \qquad \sum_i \pi_i=1
$$

That is, $\pi$ is a probability vector and also a left eigenvector of the transition matrix $P$ with eigenvalue $1$:

$$
\pi P = 1\cdot \pi
$$

For a connected undirected graph,

$$
\pi_i=\frac{k_i}{\sum_j k_j}=\frac{k_i}{2m}
$$

## Directed graphs
A(i, j) = 1 if i $\rightarrow$ j
A(i, j) = 0 if otherwise
The number of incoming connections to a node v is referred to as in-degree of v, and the number of outgoing connections as out-degree of v.

### Weighted directed graphs
In undirected networks, the “strength” of a node is the sum of weights of all edges that are adjacent to that node.

In directed networks, we define in-strength (for incoming edges) and out-strength (for outgoing edges). In signed graphs, the edge weights can be negative, representing competitive interactions. For example, think of a network of people in which there are both friends and enemies.

## Connectivity
### Weakly connected
A directed graph is weakly connected if the graph becomes connected when edge directions are ignored.

### Strongly connected
A directed graph is strongly connected if every node can reach every other node while following edge directions. A strongly connected graph must also be weakly connected.

A strongly connected component (SCC) of a directed graph is a maximal strongly connected subgraph.

### Connected component
An undirected graph is called connected if there exists a path between any pair of nodes. In undirected graphs, a connected component is a maximal set of connected nodes.

## Min-cut problem
Given a graph with a source node s and a sink node t, we define as cut(s,t) of the graph a set of edges that, if removed, will disrupt all paths from s to t. 

In unweighted networks, the min-cut problem refers to computing the cut with the minimum number of edges. In weighted networks, the min-cut refers to the cut with minimum sum of edge weights.

## Max-flow problem
Goal: compute the max amount of flow that can originate at s and terminate at t, subject to the capacity constraints and the flow conservation constraints

Method: Ford-Fulkerson algorithm
